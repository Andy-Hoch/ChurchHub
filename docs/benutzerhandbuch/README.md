# Benutzerhandbuch

← [Zur Übersicht](../README.md)

Dieses Handbuch beschreibt jede Funktion des Backends – so, wie du sie nach dem Anmelden vorfindest.

**Neu hier?** Starte mit dem [Schnellstart](schnellstart.md): Von der Registrierung bis zum Hub auf eurer Webseite oder als eigene
Seite in etwa 15 Minuten. Die wichtigsten Begriffe erklären die [Grundbegriffe](grundbegriffe.md).

## Aufbau des Backends

Nach der Anmeldung siehst du oben eine Kopfzeile (Name der aktuellen Kirche, dein Name als Link zu *Mein Konto*,
„Abmelden“) und links die **Hauptnavigation** (auf dem Handy über das Menü-Symbol oben links):

| Bereich | Menüpunkt | Seite im Handbuch |
| --- | --- | --- |
| **Hub** | Links | [Links verwalten](links.md) |
| | Design | [Design anpassen](design.md) |
| | Formulare (mit Zahl neuer Einsendungen als Badge) | [Formulare](formulare.md), [Einsendungen](einsendungen.md) |
| | Einbinden | [Auf der Webseite einbinden](einbinden.md), [Eigene Hub-Seite](eigene-seite.md) |
| **Kirche** | Einstellungen | [Kirche & Team](kirche-und-team.md) |
| | Neue Kirche | [Kirche & Team](kirche-und-team.md#mehrere-kirchen) |
| **Konto** | Mein Konto | [Konto & Anmeldung](konto-und-anmeldung.md) |

Gehörst du zu mehreren Kirchen, erscheint unten in der Navigation ein Auswahlfeld **„Kirche wechseln“**.
